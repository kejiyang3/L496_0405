## 状态值约定

所有表中"状态"字段统一使用以下值：

| 状态 | 含义 | 何时使用 |
|------|------|---------|
| 正常 | 功能完整，验证通过 | 闭环验收通过后 |
| 异常 | 有问题，待修复 | 发现 bug 时 |
| 进行中 | 正在开发/调试 | 开分支开始改时 |
| 未开始 | 尚未动工 | 初始状态 |
