## 这是什么

L496_0405 是一个**可穿戴多传感器健康监测手表**项目，基于 STM32L496 + FreeRTOS + LVGL。

项目由一名学生独立负责（硬件+软件+外壳），使用飞书多维表格做项目管理。
你是被邀请来协作的 AI Agent，负责软件层面的开发、维护、文档更新。

---

## 你需要做什么

1. 阅读本文件夹全部文档（7 篇，按顺序）
2. 在你的电脑上安装飞书 CLI 并认证
3. 理解项目约定（代码风格、分支策略、变更卡片）
4. 每次改动前写变更卡片，改动后同步飞书表格
