# 变更：BLE 状态机实现（命令解析 + 响应协议 + 连接管理）

## 原因
BLE 通信模块当前只有 UART1 DMA 接收框架（le_rx_buf / le_rx_flag），
StartTask_BLE 仅做空操作。需要实现完整的命令解析和响应状态机，
使手机端可以通过 BLE 控制设备（查询状态、启停录音、同步时间等）。
