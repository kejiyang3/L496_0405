# 变更：硬件修改（FCLK/BLE/ECG）

## 原因
1. ECG_FCLK R27=0Ω，需 22Ω 串联电阻做阻抗匹配
2. BLE 模块 R5 错装为下拉电阻（网表：R5.1→GND），应为上拉
3. ECG 3.5mm 耳机孔导联当前接在 Pin5（网表：AUDIO1.5→MAX_ECGP），MAX 输入脚是 Pin2，需短接连通

## 改动范围

### 实物（本次执行）
- [x] R27 (ECG_FCLK 串联): 0Ω → 22Ω
- [x] R5 (BLE MOD): 拆卸下拉电阻
- [x] ECG 耳机孔: 短接 Pin2-Pin5

### 原理图（下版计划）
- [ ] ECG 导联信号改到 AUDIO1 Pin2
- [ ] R5 改为上拉 10kΩ→VCC
- [ ] 网表：R27 改为 22Ω

## 影响评估
- 硬件：是
- 固件：否
- 外壳：否

## 验证方法
- [ ] 上电检查 FCLK 信号质量
- [ ] BLE 模块上电后确认 IO 电平正常
- [ ] ECG 信号通路连通性测试

## 回滚方案
- R27: 换回 0Ω
- R5: 补焊上拉电阻 10kΩ
- Pin2-Pin5: 断开短接线
