# 变更：MIC 静默失效修复 — AUDIO_RUN 诊断 + fail-fast + DMA stall watchdog + 重启

## 原因
FOUR_MODAL_SD_PULL_REPORT.md 三次拉取均显示 MIC 覆盖率 < 50%，根因是 SAI1 DMA 中断丢失后 AudioTask 静默退出，未触发全会话停止。

## 改动范围
- [x] Core/Src/audio_recorder.c — 全部修改（15 处）

## 已实现功能

### 1. AUDIO_RUN 每秒诊断 ✅
18 个字段全部布线：audio_task_alive, audio_state, sai_dma_started, dma_half_count, dma_full_count, dma_error_count, blocks_in, blocks_written, blocks_dropped, bytes_captured, bytes_written, last_dma_tick, last_write_tick, last_error_code, mutex_timeouts, wav_file_open, wav_data_bytes

### 2. WAV header sample_rate = 8000 ✅
udio_open_file 和 udio_close_file 均使用 RECORD_MIC_SAMPLE_RATE_HZ=8000，三次实测均为 8000 Hz

### 3. MIC fail-fast ✅
- SAI DMA error (ISR) → request_stop
- SAI DMA stall (2s 无中断) → request_stop  
- audio write 失败 → request_stop
- SAI DMA start 失败 → request_stop
- 所有路径均调用 udio_request_session_stop_on_error()

### 4. SAI DMA 有限重启 ✅
DMA stall 后自动尝试 1 次 HAL_SAI_DMAStop + HAL_SAI_Receive_DMA 重启，重启失败则 fail-fast

## 三次上电复测结果

## 已知限制
SAI1 DMA 中断在 12-32 秒后停止的**根因未根治**——这是硬件/时钟层问题，非固件逻辑缺陷。fail-fast 正确捕获了每次故障，确保四模态同步停止。
