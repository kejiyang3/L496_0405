## 3. 关键设计说明

### 3.1 INT 信号处理
- MAX30102 INT 为 **开漏、低电平有效**
- 上电后 PWR_RDY 会将 INT 拉低，需读 INTERRUPT_STATUS1(0x00) 才能释放
- 上拉电阻 R3 = **4.7kΩ** 到 3.3V
- 不读 STATUS1 或 FIFO，INT 永久低电平 → EXTI 只触发一次

### 3.2 I2C 总线注意事项
- MAX30102 和 ICM20948 **共享 I2C3 + TXS0104**
- I2C 地址: MAX30102 = 0x57, ICM20948 = 0x68(AD0=0)/0x69(AD0=1)
- 速度: 400kHz (Fast Mode)
- 上拉: TXS0104 内部 10kΩ + 外部并联 4.7kΩ ≈ 3.2kΩ

### 3.3 电源去耦
- VDD (1.8V): 0.1μF + 4.7μF 靠近芯片
- VLED+ (3.3V): 10μF 钽电容 + 0.1μF 靠近芯片
- LED 瞬时电流可达 50mA, VLED+ 走线需加宽

### 3.4 LED 限流
- MAX30102 内部 LED 电流由寄存器设定 (0-50mA, 0.2mA步进)
- 不需要外部限流电阻
- IR_DRV 和 R_DRV 直接连接到内部 LED 阴极

## 6. PCB 布局建议

1. MAX30102 尽量靠近板边, 传感器窗口朝外
2. VLED+ 走线宽度 ≥ 0.5mm, 电容 C3 紧靠引脚6
3. I2C 走线远离 LED 驱动走线, 避免串扰
4. INT 上拉电阻 R3 靠近 MCU 侧
5. 传感器下方铺 GND 铜皮, 避免其他信号穿越
6. PGND(8脚) 和 GND(9脚) 通过过孔单点接系统地
